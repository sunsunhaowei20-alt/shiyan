# 市演

浏览器里的 A 股风格模拟交易所。行情、盘口、涨跌停和成交都由本地模型生成，下单只动你自己的模拟资金，不会连接真实行情。

## 能做什么

- 12 只证券同时走动：白酒、新能源、银行、汽车、保险、光伏、半导体、医药、电力，以及沪深 300、创业板和黄金 ETF
- 红涨绿跌的分时 K 线、五档盘口和逐笔成交
- 市价 / 限价、100 股一手、涨跌停、佣金和卖出印花税
- 默认 T+1，可以改成 T+0
- 交易时钟可暂停，或按 1x / 4x / 16x 加快；午休和收盘可以自动跳到下一交易时段
- 账户保存在这台浏览器的 localStorage，刷新不会丢

初始资金 100 万元。

## 价格是怎么来的

每个交易日按几何布朗运动往前走，开盘和收盘波动更大。同行业共享一部分冲击，随机快讯会再推一把。价格被夹在当日涨跌停之间：主板和 ETF 为 10%，创业板、科创板为 20%。

这些价格只适合熟悉下单、盘口和 T+1，不能用来判断真实市场。
